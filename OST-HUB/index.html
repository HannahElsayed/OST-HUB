1The big idea

Think of tasting soup. You can't drink the whole pot, so you take one spoonful (the sample) to judge the whole pot (the population). Every spoonful tastes a little different. So any number you compute from a sample, like the mean X̄, changes from sample to sample.

That means a statistic is itself a random variable, and its distribution is called a sampling distribution.

💡 بالعربي: الـ statistic (زي X̄) بيتغير من عينة لعينة، فليه distribution. الفصل ده بيقولك شكل الـ distribution ده إيه.

StatisticA number computed from the sample, with no unknown parameter (X̄, S²)

2The sample mean X̄ and the CLT

Intuition: one person's weight is noisy, but the average of 100 people is very stable. More data → less spread.

E(X̄) = μ    Var(X̄) = σ²/n    sd(X̄) = σ/√n
Z = (X̄ − μ)/(σ/√n) ~ N(0,1)
  • Normal population: X̄ is exactly normal for any n (Theorem 6.1).
  • Any population, n ≥ 30: X̄ is approximately normal (Central Limit Theorem).
  • σ unknown and n large: use S instead of σ.
  • Two samples: Var(X̄₁ − X̄₂) = σ₁²/n₁ + σ₂²/n₂. Variances always add.
💡 بالعربي: الـ σ/√n جاية من Chapter 5: Var(ΣXᵢ/n) = nσ²/n² = σ²/n.

3Chi-squared χ²(ν)

Intuition: take ν standard normals, square each (so signs don't cancel), and add them. You get a "total squared error". It is always positive and skewed right.

U = Z₁² + … + Zν² ~ χ²(ν)    Mean = ν, Variance = 2ν
Independent χ²'s add: χ²(a) + χ²(b) = χ²(a+b)

The key result (Theorem 6.4): for a normal sample,

(n−1)S²/σ² ~ χ²(n−1)   and X̄, S² are independent

Why n−1, not n? We used X̄ instead of the true μ, which costs one degree of freedom. Also: E(S²) = σ² and Var(S²) = 2σ⁴/(n−1).

Notation: χ²α,ν is the point with area α to the right. Example: χ²0.05,12 = 21.03.

💡 بالعربي: χ² = مجموع مربعات ν من الـ Z. ولما نستخدم S² بنخسر درجة حرية فبتبقى n−1.

4Student's t(r)

Intuition: in real life σ is unknown, so we replace it with S. But S also varies from sample to sample, especially for small n. That extra uncertainty gives the same bell shape with heavier tails.

T = Z / √(U/r) ~ t(r),   Z ~ N(0,1), U ~ χ²(r), independent
For a normal sample: (X̄ − μ)/(S/√n) ~ t(n−1)
  • Symmetric about 0, so t1−α = −tα.
  • As the d.f. grows, t becomes N(0,1) (close enough for d.f. > 30).
  • Example: t0.025,5 = 2.571.
💡 بالعربي: لما σ مش معروفة والعينة صغيرة استخدم t بدل Z. الـ d.f. = n−1.

5F(r₁, r₂)

Intuition: F compares two variances. If they are equal, the ratio is near 1.

F = (U₁/r₁)/(U₂/r₂) ~ F(r₁, r₂),   U₁ ~ χ²(r₁), U₂ ~ χ²(r₂), independent
Two normal samples: (S₁²/σ₁²)/(S₂²/σ₂²) ~ F(n₁−1, n₂−1)

Handy facts: 1/F ~ F(r₂, r₁). If T ~ t(ν), then T² ~ F(1, ν).

6The Family Tree (memorize this)

Z ~ N(0,1)square & add ν of them →χ²(ν)
ZandU ~ χ²(r)→ Z / √(U/r) →t(r)
χ²(r₁)andχ²(r₂)→ (U₁/r₁)/(U₂/r₂) →F(r₁,r₂)
t(ν)squared →F(1,ν)

Every "state the distribution" question is just matching the expression to one of these patterns. Tip: if Xᵢ ~ N(0,σ²), then σ cancels in ratios, e.g. (X₁²+X₂²)/(X₃²+X₄²) ~ F(2,2).

7Problem-solving toolkit

5-step recipe for any problem:
  1. What is random? (X, X̄, S², a sum, a ratio)
  2. Write its mean and sd (for X̄: μ and σ/√n).
  3. Standardize: z = (value − mean)/sd.
  4. Name the distribution and its d.f.
  5. Sketch the curve and shade the area, then use the table.

1The big idea

Sometimes we care about two random variables at once (height and weight, hours studied and grade). Their joint behavior lives in a table: each cell is the probability of a pair.

Joint p.m.f.: h(x,y) = P(X = x, Y = y)
Valid if h(x,y) ≥ 0 for all pairs and ΣΣ h(x,y) = 1

Example 5.1. h(x,y) = kxy for x, y ∈ {1,2,3}. The sum is k(1+2+3)² = 36k = 1, so k = 1/36.
P(X+Y ≥ 4) = 1 − [h(1,1) + h(1,2) + h(2,1)] = 1 − 5/36 = 31/36.

Continuous case: a joint p.d.f. f(x,y) ≥ 0 with a total volume of 1 under the surface. Probabilities are double integrals over a region.

💡 بالعربي: الـ joint table فيه كل خانة = احتمال الاتنين مع بعض، ومجموع كل الخانات = 1.

3Marginal & conditional

  • Marginal = the table's margins. Add over the other variable: gX(x) = Σy h(x,y) and gY(y) = Σx h(x,y).
  • Conditional = slice, then rescale. Take one row (say Y = y) and divide by its total so it sums to 1:
    f(x | y) = h(x,y) / gY(y)
  • Continuous: sums become integrals: fX(x) = ∫ f(x,y) dy, and f(x|y) = f(x,y)/fY(y).

Example 5.4/5.6. From the books table: gX = (5/14, 15/28, 3/28) and gY = (15/28, 3/7, 1/28). Given Y = 1: f(0|1) = (3/14)/(3/7) = 1/2, f(1|1) = 1/2, f(2|1) = 0.

💡 بالعربي: marginal = اجمع الصف أو العمود. conditional = خد صف واحد وقسمه على مجموعه.

4Independence

Discrete: X, Y independent ⟺ h(x,y) = gX(x)·gY(y) for every cell
Continuous: f(x,y) = fX(x)·fY(y) for all x, y
  • One failing cell is enough to prove dependent. Example 5.8: h(0,0) = 3/28, but gX(0)·gY(0) = (5/14)(15/28) = 75/392 ≠ 42/392.
  • In the continuous case, if the support is not a rectangle (like the triangle x+y < 1), the variables are dependent.
  • Try it: load "Ex 5.1" in the Lab. It says independent, since xy/36 factors as (x/6)(y/6).

5Expectation, covariance, correlation

E[g(X,Y)] = ΣΣ g(x,y) h(x,y)    E[XY] = ΣΣ xy·h(x,y)
cov(X,Y) = E[XY] − μXμY    ρ = cov(X,Y)/(σXσY),   −1 ≤ ρ ≤ 1
  • cov > 0: X and Y tend to be high together or low together. cov < 0: one high, the other low.
  • ρ is cov rescaled to be unitless, so it is the better measure of linear relationship.
  • Independent ⟹ E[XY] = E[X]E[Y] ⟹ cov = 0. The reverse is false: zero covariance does not prove independence.
  • Properties: cov(X,c) = 0, cov(X,X) = Var(X), cov(X, aY+b) = a·cov(X,Y).

Example 5.10 (books). E[X] = 3/4, E[Y] = 1/2, E[XY] = 3/14, so cov = 3/14 − 3/8 = −9/56. Var(X) = 45/112, Var(Y) = 9/28, so ρ = −0.447. Load "Ex 5.2 books" in the Lab to see it.

💡 بالعربي: independent تدي cov = 0، بس cov = 0 مش معناها independent.

6Sums & linear combinations

E(aX + bY) = aE(X) + bE(Y)
Var(aX + bY) = a²Var(X) + b²Var(Y) + 2ab·cov(X,Y)
Uncorrelated or independent: the cov term vanishes and variances add.
  • Var(X+Y) = VarX + VarY + 2cov, Var(X−Y) = VarX + VarY − 2cov, cov(X−Y, X+Y) = VarX − VarY.
  • Constants added (the +5 in 3X − 2Y + 5) never change a variance or a covariance.
  • General: cov(a₁X + a₂Y, b₁X + b₂Y) = a₁b₁VarX + (a₁b₂ + a₂b₁)cov + a₂b₂VarY.

7The continuous case: draw the region first

Valid joint p.d.f.: f ≥ 0 and ∬ f dx dy = 1
  1. Sketch the region (for x > 0, y > 0, x+y < 1 it is a triangle).
  2. Write the limits from the picture: x from 0 to 1−y, y from 0 to 1.
  3. Integrate. Most mistakes come from wrong limits.

Example 5.3. f = kxy on the triangle. ∫₀¹∫₀^{1−y} kxy dx dy = k∫₀¹ y(1−y)²/2 dy = k/24, so k = 24.

Marginals (5.5): fX(x) = ∫₀^{1−x} 24xy dy = 12x(1−x)², and likewise fY(y) = 12y(1−y)².

Conditional (5.7): f(x|y) = 24xy/(12y(1−y)²) = 2x/(1−y)², 0 < x < 1−y. For y = ¼: f(x|¼) = 32x/9 on (0, ¾), so P(X > ½ | Y = ¼) = ∫½¾ 32x/9 dx = 5/9.

Dependent because the support is a triangle, so f ≠ fX·fY. Also E[XY] = 2/15.
